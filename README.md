# Nextronix Global — Advanced Agency Website

Production-oriented React + Vite + TypeScript agency website based on the supplied Phase 1 visual language.

## Stack
- React + TypeScript + Vite
- Tailwind CSS
- Framer Motion
- GSAP + ScrollTrigger
- Lenis
- Lucide React
- Swiper
- React Router

## Routes
- `/`
- `/about`
- `/services`
- `/services/bpo`
- `/services/website-development`
- `/services/digital-marketing`
- `/services/seo`
- `/work`
- `/work/:slug`
- `/contact`
- `/privacy-policy`
- `/terms-and-conditions`

## Run
```bash
npm install
npm run dev
```

Build:
```bash
npm run build
```

## Content notes
The supplied Phase 1 metrics are retained visually but explicitly marked as demo/reference metrics in the production UI. Replace them with verified business data before publishing. Testimonial identities are generic placeholders as requested.

The contact form is intentionally frontend-only and is prepared for `POST /api/contact`; it does not claim to send email until a backend is connected.

## Visual foundation
The implementation preserves the supplied Phase 1 DNA:
- deep black / white contrast
- electric royal blue
- floating glass navigation
- Space Grotesk + DM Sans
- large editorial headings
- rounded image compositions
- subtle borders and shadows
- metric counters
- trust/technology strip
- restrained glow and motion
- responsive mobile navigation
